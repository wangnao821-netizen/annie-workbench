## 二、关键技术决策

### 1. Python 后端随应用运行的策略

**V1：Electron 主进程 spawn 外部 Python 进程**（用已装好的 venv/python），不做 PyInstaller。

- 主进程启动时：检查端口 8000 是否被占用（占用则提示/换端口）→ spawn
  `python run_backend.py --port <port>`（python 路径可配置）→ 轮询 `/api/health`
  就绪后显示主窗口 → 应用退出时优雅终止后端进程。
- 理由：PyInstaller 对 pydantic v2（pydantic-core Rust 原生）、sqlite-vec（原生扩展）、
  liteparse 依赖极易踩坑且体积巨大（200-400MB），风险高收益低；Vera 是本地单用户，
  已有稳定 venv。**PyInstaller 列为 V2 优化**（先出可运行版本，后续再评估内嵌）。
- 兼容：若检测到系统 python 且 venv 存在则优先用 venv；python 路径写入 electron 配置，
  首次引导可让用户指定（默认自动探测）。

### 2. 前端加载方式

- **开发**：Electron 加载 `http://localhost:3000`（vite dev）+ spawn 后端 dev。
- **生产**：Electron 加载前端 `dist/index.html`（file:// 或本地静态服务），
  API 仍走 `http://localhost:8000`（前端 BASE_URL 默认已指向它）。

### 3. 窗口（frame: false + 前端标题栏）

- `BrowserWindow { frame: false, ... }`（不做 transparent，避免 Windows 最大化/材质问题）；
- 前端 TopNavBar 增加窗口按钮组（最小化/最大化/关闭）——**条件渲染**：
  检测 `window.veraElectron`（preload 注入）存在才显示；浏览器预览不显示（零影响）；
- 圆角：`#app-shell` 的 `--window-radius: 12px` 已就绪；**最大化时圆角变直角**
  （IPC 事件通知前端切 class 或 CSS 变量覆盖）；
- 拖拽区：`.electron-drag` 已挂在 TopNavBar（F-43 补丁三），按钮自动 no-drag。

### 4. 配置与首次引导

- electron 运行时配置 `electron/config.json`：python 路径、端口、窗口记忆（可后续）；
- 首次启动：检测 `.env` 缺失或 CLIENT_FILES_ROOT 为空 → 打开引导对话框
  （选客户文件根目录、填 LLM key[可选]、显示 .env.example 说明）→ 主进程写 .env
  （**不硬编码 key，仅写用户输入**）；
- 不写客户文件夹任何内容（红线），只读。

### 5. 托盘 / 通知 / 自动更新（WO-05 范围）

- **托盘**：最小化到托盘 + 托盘菜单（显示/退出）；关闭按钮行为 = 最小化到托盘（可配置）；
- **系统通知**：Electron Notification 骨架（后端通知 → IPC 转发，V1 先接
  逾期/跟进提醒）；保留接口；
- **自动更新**：electron-updater 骨架（V1 不接分发渠道，配置就绪待定）；
- **端口冲突**：启动时探测 8000 占用 → 自动换 8000-8010 可用端口并写入前端
  `VITE_API_URL` 上下文（生产模式通过注入全局变量），或提示用户关闭占用进程。

## 三、工程结构

```
D:\vera-workbench\
├── electron\
│   ├── main.js          # 主进程：窗口/托盘/后端 spawn/配置/IPC
│   ├── preload.cjs      # 暴露 window.veraElectron（窗口控制/版本/通知）
│   ├── package.json     # electron + electron-builder（独立依赖，不污染前端）
│   ├── config.json      # 运行时配置（python/端口/窗口）
│   └── build\           # 图标（app.ico 等）
├── ui\vera-工作台 (72)\  # 前端（构建 dist 后由 electron 加载）
└── run_backend.py       # 后端（spawn 目标）
```
