# 信贷案卷全生命周期处理规范与材料清单实施总纲

## 一、三类案件全生命周期处理矩阵

| 业务维度 | 🆕 1. 新建案件 (New Cases) | 🔥 2. 正在进行的导入案件 (In-Flight Active) | 📁 3. 历史存档案件 (Settled / Archive) |
| :--- | :--- | :--- | :--- |
| **客户状态** | 刚来咨询 / 刚签 Broker 协议 | 材料收集中 / 银行审批中 / 补件复议中 | 已经成功放款交割 / 历史结案 |
| **📄 案卷全景备忘录** | 根据初始录入，**生成标准 6 维初始备忘录框架** | 提取现有文件与事实，**生成包含当前真实卡点与对策的 6 维备忘录** | 生成包含放款额、结算银行、终态利率的**历史结案档案备忘录** |
| **📋 材料清单与催件** | **智能推荐 ➔ 勾选 ➔ 一键催件**：<br>根据身份/雇佣/银行推荐 5~6 项标准清单，2秒勾选，一键生成中/英催件清单 | **自动对齐 ➔ 缺口透视 ➔ 在途补件**：<br>• 已递交：基础材料默认 100% 齐备；<br>• 收材料：按本地文件自动打勾，缺口置顶，一键生成“在途补件微信” | **静默 100% 齐备归档 (免打扰)**：<br>不提示任何缺口；未来该客户做二次转贷时，**一键继承护照/地契等恒定证件**，仅催最新流水 |
| **⏳ 沟通与邮件时序** | 初始为空，随着存入第一封申请回执，**实时向下追加时序** | 自动读取文件夹内 `.msg/.eml`，**提取审批官姓名、案号、卡点历史，铺满右侧时序证据链** | 记录最终批复通知、交割单等关键里程碑节点 |
| **🧠 AI 核心协同场景** | • 协助进行借贷能力测算<br>• 推荐最佳贷款产品与银行 | • **协助起草发给 BDM 的申诉/复议邮件**<br>• 依据相似历史先例提供破局论据 | • 监控固定利率到期与转贷时机<br>• 自动触发客户周年关怀与降息机会 |
