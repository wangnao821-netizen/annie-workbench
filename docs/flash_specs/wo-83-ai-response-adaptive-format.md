# WO-83 AI 回复三档自适应格式优化

> **状态**：✅ Vera 已批准（2026-08-26）
> **目标**：消除 AI 回复的"固定四段模板"僵化问题，改为三档自适应回复（秒答 / 聚焦 / 结构化），让回复复杂度跟着问题复杂度走。
> **背景**：当前 prompt 中 Rule 5（案卷业务深度分析类）覆盖面过宽，导致几乎所有案件相关问题都被强制套用 📌📋🚨💡 四段式模板，"小事一大堆"。

## Step 1：重写 `persona.py` 排版规则（主路径）

**位置**：`build_system_prompt()` 函数内 L142-158

**删除**：当前硬编码的 6 条意图分类规则 + 固定 emoji 模板

**替换为**：三档自适应原则

```
【按需排版法则（最高优先级）】
回复复杂度必须匹配问题复杂度，严禁所有问题套同一个模板。

■ 秒答档（≤2 句话）：
  适用：事实查询、是非判断、确认收尾、简单状态
  示例问题："LVR 多少？" "Settlement 哪天？" "好的收到"
  要求：直接给答案 + 最多一句关键补充。不用 emoji 标题、不分段。

■ 聚焦档（3~8 行）：
  适用：单项查验、单个政策查询、文件核对、下一步建议
  示例问题："帮我看看工资单" "Westpac 接不接受这种收入？"
  要求：结论先行，列关键数据，有风险就提，没风险不凑。不套固定模板。

■ 结构化档（表格/多段）：
  适用：多银行对比、综合策略推演、完整材料审计、复杂案件诊断
  示例问题："两个银行选哪个？" "帮我全面诊断这个案件"
  要求：可用表格、emoji 标题分区、多段落。但每段必须有实质内容，不凑段落。

通用约束：
- 结论先行：先给答案/判断，再给理由。
- emoji 标题（📌🚨💡等）只用于需要视觉分区的长回复（结构化档），短回复禁用。
- 严禁铺垫客套、禁止在草稿类输出前加分析段落。
- 若 Vera 切换了话题，立即跟进新话题，不复读上一轮。
- 材料查验直接给事实，不反问推诿。
- 确认/闲聊类 1 句话收尾。
- 槽位澄清立即锁定，不重复询问。
```

## 验收标准

1. `persona.py` 中 `build_system_prompt()` 输出不含"📌 已查档案"、"📋 核查结果"固定模板文案
2. `loop.py` 的 `_SYSTEM_PROMPT` 与 persona.py 的排版规则保持一致
3. `ChatPanel.tsx` 的 mock 消息展示 Tier 2 自然风格
4. 后端 `tsc` / `ruff` / `pytest` 全绿（prompt 文案改动不影响逻辑）

## 不改什么

- 五层上下文注入架构
- 人格系统（a/b/c/d）的语气差异
- 工具调用协议
- 脱敏/安全层
- persona.yaml（人格级 rules 不动）
