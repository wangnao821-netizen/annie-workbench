## 四、前端与后端契约核对结论

对前端 `services/api/*.ts` 全部调用路径与方法逐一对照后端路由，**无缺路由、无方法错**；
重点请求体（清单新增 name_zh / 委派 delegate_to / 文件夹 mode+path / 申报 files+folder）
前端类型与后端 schema 逐字段一致。

**需注意的边界**：
- LLM 端点（chat/declaration-check/policy-check/共创生成）需配置 DEEPSEEK/GEMINI key，
  当前 .env 未配置——真机联调前必须配（含 fallback 配置）。
- FileDrawer 的 Office 原样预览依赖后端 folder files 带 file_id（WO-48 已实现，
  但 folder import 上传的新文件不落库 CaseFile，暂无 file_id，仅显示解析文本）。
