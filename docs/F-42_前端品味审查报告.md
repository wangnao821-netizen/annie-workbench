## 二、问题清单（按修复优先级）

### P0 · 色彩收口（F-41c 未竟之业，量最大）

1. **紫色失控，语义漂移**。全站 509 处 `purple-XXX` 硬编码 + 52 处 `var(--purple)` + 2 处 `#8b5cf6`。
   F-41 定稿"紫色仅保留为智能 AI 特殊高亮辅助"，实际它同时代表 4 种含义：
   AI 高亮（BrainChat 工具、计算器）、澳洲时区（AuTimePanel 整面板）、老板决策（筛选 tab/徽章）、
   关联案件（DetailPanel 横幅）。一个颜色 4 种含义 = 没有含义。
   **处置：紫色只留给 AI 相关；时区/老板/关联案件分别换 accent / yellow / blue 语义。**
2. **Tailwind 默认色叛逃**。`rose/amber/emerald/indigo/blue/gray` 直接使用遍布 80 个文件
   （HomePage 22 处、BrainChat 21 处、CasePanorama 15 处）。切到 ivory/护眼绿/柔光粉主题时
   这些颜色纹丝不动，主题体系形同虚设。全部应收敛到 `var(--red/--yellow/--green/--orange/--accent)` + soft 变体。
3. **黑白透明度硬编码**。`bg-black/5 dark:bg-white/10` 这类遍地（预估 300+ 处），
   在 sand/ivory 主题下显脏。应收成 `--bg-subtle` 一类令牌。
4. **AI 渐变残留**：Sidebar logo（accent→purple）、首页专家贴士（indigo→purple→amber 三色）、
   头像（amber→rose→purple）、CasePanorama 空态（purple→pink）。taste-skill 点名的"AI 指纹"。

### P0 · 动效统一（apple-design 专项，改动小感知强）

1. **Spring 语言碎片化**：16 种 spring 参数组合（damping 20/24/25/26/28/30/35 × stiffness 300-500）。
   Apple 标准：默认阻尼 1.0（无过冲），只有甩动/投掷才允许弹跳。全站浮层普遍带轻微 overshoot。
   **处置：定 2 档 house style——浮层/下拉/弹窗 `damping:25, stiffness:300`；
   卡片 hover/抽屉拖拽才允许 `stiffness:350-400, damping:20-25`；其余 14 种全部收编。**
2. **Reduced-motion 覆盖率 42%**：534 个 motion 组件，仅 76/180 文件有 `useReducedMotion`。
   关键坑：index.css 的全局 `prefers-reduced-motion` 拦不住 Motion 库的 JS spring 动画，
   必须组件级补分支。重灾区：TaskCard(12)、GlobalExperienceTab(10)、CaseFolderCard(8)、
   OverdueDetail(6)、FloatingAI(6)。
3. **同族元素手感不一致**：弹窗进入位移 `y:6/8/10/12` 四种；卡片 hover `y:-1/-2/-3` 三种。
4. **弹层未锚定触发源**：通知/头像/时区下拉从中心展开，未从触发按钮 origin 生长。

### P1 · 字号体系与可读性

1. 全站 ≤12px 字号共 1459 处：12px×659、11px×353、**10px×404、9px×39**。9-10px 中文基本不可读。
2. 796 处固定 px 字号（`text-[10px]` 等）不随系统字号缩放（违反 rem 原则）。
3. 建议：建立字号令牌（12/13/14/16 为主梯队），9-10px 消灭，11px 只留给时间戳，
   关键操作和金额 ≥12px，区块标题 ≥14px。

### P2 · 表面层级与结构

1. 玻璃拟态 56 处，静态容器（侧栏/面板/header）也在用玻璃——只应留给浮层。
2. 三套导航并存：TopNavBar 头像下拉（知识/档案/草稿/设置）＋ CaseListSidebar 底部 tab（首页/看板/统计/设置）——重复。
3. `Sidebar.tsx` 已不被 AppShell 引用（死代码，应删）。
4. 主题切换 4 入口：顶栏 SunMoon 循环 + Sidebar Palette + Sidebar logo 点击 + 设置页 ThemePicker。

### P3 · 细节

1. emoji 当 UI 元素混排（快捷提问 🧮📂、徽章 👑📧、状态 ✅⛔）。渠道徽章建议换 lucide 图标。
2. 圆角令牌 `--radius` 定义 0 消费（全站 rounded-xl 497 处等，统一性尚可但改不了策略）。
3. **硬编码 mock 数据泄漏到 UI**：首页贴士写死"陈伟案件 (NAB)"、通知里写死客户名——联调前清理，PII 风险。
4. 拖拽分隔条 PanelDivider 用 `bg-purple-500/50`——紫色硬编码。
5. 过渡动画 spring 参数各组件不一致（详见 P0 动效）。
