# Annie Workbench 开发与协作最高宪法 (Constitution)

本文档作为本工作区的核心规则（Rules），所有对话、子代理、工具调用均必须严格遵循。

## 核心流程铁律：
1. **现状与根因求证**：只读只查，绝不动手改源码；向用户汇报现状与根本原因。
2. **方案推演与沟通**：提供 2~3 个方案对比优劣与影响面，多轮沟通推演。
3. **用户批准后方可行动**：给出实施计划清单，明确获得用户“确认/通过”后才写代码。
4. **精确实施与验证**：按计划编码，本地通过编译与类型检查，不擅自做计划外操作。
5. **验收汇报**：交付改动说明与证据，等待用户体验并决定是否打包。
